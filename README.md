# Instructions for Using the Website

Go to esap.onrender.com in your browswer

## 1. Start on the homepage

On the homepage, you can:
- look at featured games
- view recommended games
- open the full game list
- create or manage your profile

## 3. Browse the game catalog
On the "Game List page, you can choose to 
- search for a game by name
- filter games by genre
- filter games by supported language
- filter games by tags
- sort games by name, rating, or price

## 4. Open a game page

Click any game card to open the game details page. There you can read the game description and see review information.

## 5. Create a profile

Go to the profile section and create a new profile. Choose the genres, languages, and tags that match the kinds of games you like.

## 6. Save your profile

After you save your profile, the website will use it to recommend games that better match your interests.

## 7. Manage your profiles

You can:
- create a new profile
- edit an existing profile
- delete a profile

## 8. Use the website regularly

Return to the site anytime to:
- explore more games
- update your preferences
- see new recommendations
