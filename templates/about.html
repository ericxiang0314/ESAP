About the project

Building a smarter Steam game recommendation experience

The goal of this project is to recommend games on Steam based on a user's hardware, preferences, and gameplay interests. The first version focuses on collecting PC-spec information and storing it securely in a simple backend workflow so the recommendation engine can be expanded later.

Planned improvements include using Kaggle game metadata, rating data, genre tags, and minimum hardware requirements to estimate how well a game fits the user's system. We also hope to bring in NLP from reputable sources like IGN to identify descriptors and keywords that make matching more accurate.

The site is designed to grow into a polished experience with a working form, recommendation results, and a public-facing deployment path such as Render, with MongoDB or another store used for longer-term data needs.
